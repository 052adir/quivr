## חדש — המערכת "חושבת כמו מנכ״ל" (לא כמו תוכנה)
כל מסך עונה על שאלה אחת: *איך זה עוזר להרוויח יותר, לחסוך, או להחליט טוב יותר?*
נוספו 4 מסכים שממירים נתונים ל**כסף** ול**פעולות**:

- **🚩 מנהל הבוקר** — "בוקר טוב, מרדכי". מסכם כמה כסף בורח וכמה אפשר להרוויח, ומדרג:
  *"אם יש לך רק שעה אחת היום — עשה את 3 אלו"*.
- **🪙 כסף** — "כסף שבורח" (פוד קוסט, שכר, חוסרי טבח, מנות מפסידות, פערי קופה) מול
  "כסף שאפשר להרוויח" (פער ליעד, אירועים, לקוחות לסגירה, ממוצע הזמנה) — הכול ב-₪.
- **🎚️ סימולטור** — "מה יקרה אם…": העלאת מחיר מנה/פיצה, הוספת מלצרית, ביטול משמרת —
  שווי שנתי ב-₪ בזמן אמת.
- **💡 החלטות** — כל החלטה עם מחזור חיים (רעיון → בדיקה → ביצוע → מדידה → למידה)
  ומדד **ROI** לכל אחת.

## חדש — ייבוא מסמכים אמיתי (העלאת קובץ מהמחשב)
מסך **ייבוא מסמכים** כבר לא טקסט בלבד — יש רכיב `input type="file"` אמיתי + גרירה:
- **Excel (xlsx)** ו-**CSV** נקראים ומנותחים בפועל בדפדפן (ללא שרת) —
  זיהוי עמודות לפי כותרות (תאריך, מחזור, מזומן, אשראי, שם, תפקיד, עלות, ספק, סכום…).
- **תצוגה מקדימה** לפני קליטה: שם הנתון · ערך שחולץ · לאיזו טבלה ייכנס · ערך קיים ·
  **רמת ביטחון** · סטטוס. **שום דבר לא נכנס בלי לחיצה על "אשר קליטה"**.
- **Z יומי** → יומן; אם היום קיים: "השלם רק ריקים" / "החלף". **תמחיר עובדים** → כרטיסי עובד.
- **PDF** — חילוץ טקסט אמיתי בדפדפן (FlateDecode + עברית cp1255): הטקסט מוצג
  לעריכה ואז מנותח (זיהוי בסיסי; PDF סרוק/תמונה → OCR בשלב הבא).
- בענן (Supabase): קבצים ל-Storage פרטי + טבלאות `uploaded_documents` /
  `document_extracted_data`, עם API routes `/api/documents/{upload,parse,approve}`.

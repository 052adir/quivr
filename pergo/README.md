# פרגו — לוח מכוונים 🏎️

אפליקציית ווב לניהול המסעדה החלבית **פרגו** (צור הדסה). לוח מחוונים בהשראת
לוח המכוונים ברכב — שעונים שמראים את מצב העסק בזמן אמת ונורות שמתריעות כשצריך
לשים לב למשהו.

## מה יש בגרסה 1

- **שלושה שעוני מחוונים**
  - מחזור חודשי מול היעד (₪210,000) — כמה עכשיו, כמה נשאר, אחוז מהיעד
  - קצב חודשי משוער — הערכה לפי הממוצע היומי
  - ממוצע הזמנה מול יעד (₪90)
- **נורות התרעה** בסגנון לוח מחוונים — מחזור נמוך, אירוע/חג מתקרב, משימה תקועה, הכל תקין
- **לוח שנה עסקי** (עברי + לועזי) שמזהה אוטומטית את החגים והתקופות הקרובים
  (בין המצרים, תשעה באב, ראש השנה, יום כיפור, סוכות, חנוכה, פורים, פסח, שבועות),
  מציג ספירה לאחור, המשימה העסקית המומלצת לכל תקופה, ומי האחראי
- **לוח משימות צוות** — מרדכי / אנה, לפי תחום וסטטוס (מתוכנן / בתהליך / תקוע / בוצע)
- **הזנת מחזור יומי** עם גרף מגמה, והנתונים נשמרים במכשיר

## איך מריצים

זו אפליקציית ווב סטטית בלי צורך בהתקנה. אפשר פשוט:

```bash
# אפשרות א' — לפתוח ישירות בדפדפן
open pergo/index.html      # (או לגרור את הקובץ לדפדפן)

# אפשרות ב' — עם שרת מקומי (מומלץ)
cd pergo && python3 -m http.server 8080
# ואז לגלוש אל http://localhost:8080
```

## נתונים

הנתונים נגזרו מקובץ האקסל שבנית ("לוח מכוונים"). נכון לעכשיו הכל נשמר מקומית
בדפדפן (`localStorage`). זו נקודת פתיחה — בהמשך אפשר לחבר מסד נתונים בענן
(למשל Supabase) כדי שכל השותפים יראו את אותם נתונים בזמן אמת, ולהוסיף מודולים
נוספים (תזרים, משפך לקוחות פוטנציאליים, דוחות).

## מה בהמשך (רעיונות לשדרוג)

- מודול תזרים מזומנים ובקרת אמצעי תשלום (מהטאב "תזרים" באקסל)
- ניהול משפך לקוחות פוטנציאליים (הטאב "לקוחות פוטנציאליים")
- הזנת נתוני יומן מלאים (עסקאות, משלוחים, איסוף, ישיבה במקום)
- התראות אוטומטיות (וואטסאפ/מייל) לפני חג לאחראי המשימה
- אחסון בענן ושיתוף בין השותפים
- הפיכה ל-PWA להתקנה בטלפון
